How it worksGet CL4NK

The website isn't the brain.

This is CL4NK Headquarters: documentation, source, roadmap and eventually signed downloads. The companion itself is being designed to run locally, keep its living memory on your machine, and connect to replaceable local model runtimes. If this website disappears, your CL4NK should not forget who it is.

Local-first

The core experience should not require a permanent cloud account or hosted subscription.

Portable identity

Personality, memory and preferences should belong to the user and move between machines.

Open source

Inspectable, remixable and built from mature open-source infrastructure wherever possible.

Current mission

Memory

SQLite-backed local memory with retrieval, forgetting, summaries and explicit user controls.

Runtime

Replaceable adapters for Ollama, llama.cpp-compatible servers and future local engines.

Desktop

A small Tauri shell for Windows, macOS and Linux rather than another browser tab pretending to be a companion.
