Roadmap

BUILD THE
ROBOT.

Public milestones for turning CL4NK from a personality experiment into a portable local companion.

01 · Identity

Canonical personality core, configuration format and portable identity bundle.

02 · Memory

SQLite store, memory types, importance, retrieval, summaries, forgetting and user controls.

03 · Runtime

Ollama and llama.cpp-compatible adapters with model discovery and streaming chat.

04 · Desktop

Tauri shell for Windows, macOS and Linux with straightforward installation.

05 · Tools

Permissioned files, web, notes/tasks and optional local code execution.

06 · Voice

Optional local speech input/output without making voice a cloud dependency.

Current phase: foundations and public headquarters. Desktop binaries are not released yet.
CL4NK Industries™ · Roadmap is directional, not a promise carved into suspicious metal.
